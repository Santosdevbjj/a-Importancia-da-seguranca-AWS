Adequação à LGPD Utilizando AWS

Objetivo
Garantir que os dados pessoais dos clientes da Farmácia Vida+ sejam tratados de acordo com a Lei Geral de Proteção de Dados (LGPD).




Dados Tratados
A empresa armazena:
Nome completo
CPF
Endereço
Histórico de compras
Informações de pagamento
Receitas médicas 



Riscos Identificados
Vazamento de dados
Acesso indevido
Exclusão acidental
Compartilhamento não autorizado




Controles Implementados
AWS IAM
Controle rigoroso de acesso.
AWS CloudTrail
Auditoria de todas as ações realizadas.
AWS GuardDuty
Monitoramento contínuo de ameaças. 




Benefícios para LGPD
Confidencialidade
Somente usuários autorizados acessam dados.
Integridade
Proteção contra alterações indevidas.
Disponibilidade
Acesso seguro aos dados quando necessário.
Rastreabilidade
Registro de todas as operações. 




Conclusão
A utilização dos serviços AWS fortalece significativamente a conformidade da organização com os requisitos da LGPD. :::
