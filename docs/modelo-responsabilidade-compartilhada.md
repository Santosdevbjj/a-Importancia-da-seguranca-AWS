Modelo de Responsabilidade Compartilhada da AWS

Introdução

A segurança na nuvem AWS é baseada no Modelo de Responsabilidade Compartilhada.

Nesse modelo, a AWS é responsável pela segurança da infraestrutura da nuvem, enquanto o cliente é responsável pela segurança dos recursos implantados na nuvem.

---

Responsabilidades da AWS

A AWS é responsável por:

- Data Centers
- Hardware
- Rede física
- Infraestrutura global
- Virtualização
- Segurança física

Essas responsabilidades são conhecidas como:

"Segurança DA Nuvem"

---

Responsabilidades do Cliente

A Farmácia Vida+ é responsável por:

- Configuração do IAM
- Gerenciamento de senhas
- Criptografia de dados
- Configuração de rede
- Controle de acesso
- Monitoramento

Essas responsabilidades são conhecidas como:

"Segurança NA Nuvem"
